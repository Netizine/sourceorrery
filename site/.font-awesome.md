# Font Awesome integration

- Method: locally installed SVG Kit package, rendered at build time.
- Kit ID: `515c69ad68`; installed revision: **4**, package version **1.0.4**.
- Package: `@awesome.me/kit-515c69ad68` from `https://npm.fontawesome.com/`.
- This revision exports **duotone thin** (`fadt`), brands (`fab`) and custom
  icons (`fak`). It does not contain duotone light.
- Custom mark: `sourceorrery` from `icons/kit/custom`.
- Use `src/components/FAIcon.astro` in components and `iconHast` from
  `src/lib/font-awesome.mjs` in Markdown plugins. Both use the same package.
- SVG paths are emitted into HTML. No Kit JavaScript, third-party fonts
  or runtime icon requests are permitted. Optional website analytics are a
  separate consent-controlled integration documented on the privacy page.
- Decorative icons are hidden from assistive technology; controls need labels.
- Theme colours and duotone opacity live in `src/styles/paper.css`.
- Authentication: `.npmrc` uses `${FONTAWESOME_NPM_AUTH_TOKEN}`. Supply it in the
  environment/CI secrets only; never write an actual token into tracked files.
- After kit changes: authenticate, run `npm update @awesome.me/kit-515c69ad68`,
  review exported styles and run `npm test` and `npm run build`.

Reference: https://docs.fontawesome.com/web/use-with/ai-agent-tools
