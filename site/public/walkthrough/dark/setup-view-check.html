  VIEW CHECK                                                                                                            
                                                                                                                        
  The view check is asked before a person sees a value or the vault's contents: `secret get --reveal`, `ui`, `audit`.   
  It is a check, not encryption. `run`, `check`, `init` and the SDKs never ask it, so programs start without a prompt   
  while a key read out at the keyboard, by you or by an agent, asks for more.
