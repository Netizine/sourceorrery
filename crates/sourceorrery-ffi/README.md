# sourceorrery-ffi

The C ABI of [SourceOrrery](https://sourceorrery.ai): a shared and a static
library with a C header, `sourceorrery.h`, over the SourceOrrery core.
Secrets belong to the runtime, not the repository.

**You probably want something else.**

* To read secrets from Rust, use
  [`sourceorrery`](https://crates.io/crates/sourceorrery), the read-only
  client; there is no reason to go through C from Rust.
* To read secrets from Java, .NET, Go, C, C++ or PHP, use that language's
  SDK; each calls this library for you
  ([SDKs](https://sourceorrery.ai/sdks/)). Prebuilt libraries with the C
  and C++ headers are in the `sourceorrery-ffi-<version>-<target>`
  archives on the
  [GitHub releases](https://github.com/Netizine/sourceorrery/releases/latest)
  page.
* Use the separately installed CLI to create vaults and set secret values:
  [CLI installation guide](https://sourceorrery.ai/getting-started/#install).

This crate is published so that the library can be built from crates.io
for a platform the release does not cover, and so that a binding for
another language can be built on it.

## What is in it

* `so_reader_*` and `so_project_*`, **read-only**: open a vault the way the
  CLI does, read values and metadata, resolve `sourceorrery://` references,
  load a `sourceorrery.toml`. These are the application SDKs' public
  read-only surface; write-capable tooling entry points remain separate.
* `so_vault_*` and `so_secret_*`: the full lifecycle, for tooling that
  administers vaults.
* Values in caller-owned buffers that `so_bytes_free` zeroises; errors as a
  stable code, a message and a hint that says what to do.

The crate builds a `cdylib` and a `staticlib`. The header is generated by
cbindgen and kept in the crate as `include/sourceorrery.h`. The full
reference: [C ABI](https://github.com/Netizine/sourceorrery/blob/main/bindings/README.md)
and the [C guide](https://sourceorrery.ai/sdks/c/).

## Features

`os-keyring` (default) enables the OS credential store and `remote`
(default) the providers; without them (`--no-default-features`) vaults open
with their recovery keys only.

## Stability

Pre-1.0. The C ABI carries a contract version (`so_contract_version`);
the SourceOrrery crates are released together with one version number.
